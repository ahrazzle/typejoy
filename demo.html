Welcome to Typejoy!

A rhythm-typing game where your keystrokes land on the beat. Type fast, type accurately, and watch the feedback come alive.

How to Play

  1. Enter a word or phrase in the Content box (or keep "hello world")
  2. Adjust BPM (speed) and Difficulty (timing tightness)
  3. Click ▶ Start Game — the keyboard will glow
  4. Type the highlighted character shown in the Type This row above
  5. A floating orange keycap shows which key to press — hit it as it pulses!
  6. Wrong keys are ignored. Press the right key at the right time for the full particle burst

The orange glow intensifies as the note approaches. Land it inside the timing window for Perfect, Great, or Good.
